🚀 **Lofi Pomodoro Timer — Rediseño completo + Deploy**

Hoy nos sumergimos en el diseño v0 de nuestra app de productividad y el resultado habla por sí solo.

**Lo que construimos:**

🎨 **Nuevo design system** con tokens oklch, Geist fonts y estética dark-only minimalista
⏱️ **Timer interactivo** con ring visual, chime al completar y auto-advance cada 4 ciclos
📋 **Kanban Board** con flechas, check circles y empty states con borde dashed
📅 **Calendario integrado** — vista mes/semana para asignar fechas a tareas
🎵 **Lofi Player** con streaming de SomaFM Groove Salad
📱 **PWA completa** — instalable, offline-ready, manifest + service worker

**Stack técnico:**
→ Svelte 5 (runes) + Tailwind CSS v4 + Vite
→ Deploy en Vercel como SPA estática
→ Flask como serverless API (listo para features futuros)

**Decisiones de diseño:**
- Dark forzado — sin toggle de tema
- Paleta cálida: `oklch(0.72 0.17 48)` como primary orange
- Layout responsive: 2 columnas en desktop, sticky sidebar
- Transiciones suaves y microinteracciones en cada elemento

**Próximos pasos:**
→ Integración con Google Calendar API
→ Sync bidireccional de tareas
→ Stats dashboard con gráficos

El diseño no es solo cómo se ve, es cómo funciona. Cada token, cada transición, cada pixel tiene un propósito.
